# ETERNA FRAGANCIA

Tienda online construida con HTML, CSS y JavaScript vanilla. Vite se utiliza como servidor de desarrollo y herramienta de build.

## Ejecutar localmente

```bash
npm install
npm run dev
```

La aplicación principal está en `index.html`; las páginas adicionales están en `pages/`, la lógica en `js/` y los estilos en `css/`.

## Build

```bash
npm run build
```
